# UI Kit —— HUITOU 控制台

对话优先的 AI 投手工作台，布局依据用户提供的真实产品截图（`uploads/pasted-1786603217753-0.png`）还原：

顶栏的「工作台／广告投放」切换两套界面：

**工作台**（`WorkspaceScreen.jsx`）—— 组织级视图：顶栏 + 左侧导航（首页 / 广告账户 / 广告计划 / 平台接入，组织组（团队管理、经验库、系统设置），个人组（个人设置））+ 右侧内容页。首页是跨账户的汇总指标、需要处理的问题列表与智能体动态；「广告账户」是六个账户的总表，点「进入」切到该账户的对话工作台。

**广告投放** —— 单账户的对话工作台：

- **72px 顶栏** —— 标识 + 「工作台／广告投放」胶囊分段控件 + 通知铃（含红点）
- **264px 左侧栏** —— 账户切换卡、新聊天、设置、历史对话列表（悬停显示删除）、底部用户
- **中间会话区（常驻）** —— 面板标题行、空状态提问语与建议问题胶囊、底部输入框（@广告 提及标签、附件／@、语音、深色圆形发送键）
- **右侧数据面板** —— 点击图标栏后在会话右侧展开，会话不消失：用户在左边对话，右边看数据和决策。面板可关闭，宽度自适应（最小 420px），内部界面在窄栏下自动改为单列
- **64px 右侧图标栏** —— AI决策、账户概览、广告投放、达人、商品，带未读红点

「AI决策」面板内分「待执行决策／诊断结论」两个标签页。

智能体回复由 `ReplyBlocks.jsx` 中的可组合区块拼成：文本、指标条、图表卡、表格卡、决策卡（含置信度与「立即执行」按钮）、脚注。在会话里点「给我昨天的日报」或「账户诊断」可看到完整效果。

打开 `index.html`。这是一个可点击流程：可发送消息并得到示例回复，点击建议胶囊直接提问，广告系列表格可筛选与多选，策略页会弹出确认框并触发提示条。

| 文件 | 界面 |
|---|---|
| `AppShell.jsx` | 顶栏、会话侧栏、右侧图标栏、面板标题区 |
| `WorkspaceScreen.jsx` | 工作台：组织侧栏、今日汇总、账户总表 |
| `ChatScreen.jsx` | 会话空状态、消息气泡、输入框 |
| `ReplyBlocks.jsx` | 智能体富文本回复的区块渲染器 |
| `OverviewScreen.jsx` | 指标行、花费／CPA 图表、智能体动态 |
| `DiagnosisScreen.jsx` | 按影响排序的结论列表 + 证据详情面板 |
| `StrategyScreen.jsx` | 建议变更、护栏、推理过程、应用确认弹窗 |
| `CampaignsScreen.jsx` | 可筛选、可多选的数据表格与分页 |
| `SettingsScreen.jsx` | 数据连接列表与工作区设置 |
| `data.js` | 各界面共用的示例数据 |

所有界面均由已发布的组件拼装而成，不在此处重新实现任何基础组件。全部数字均为虚构，不代表任何真实的 HUITOU 账户。
