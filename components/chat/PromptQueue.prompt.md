# PromptQueue

输入框上方的提问队列。AI 还在生成时，用户可以继续发送提问，新的提问排入队列，当前回答结束后按顺序自动发出。

## 何时用

- 单会话串行生成的对话界面：回答期间输入框不该被锁死。
- 需要让用户看到「我刚发的那句去哪了」。

## 规则

- 位置固定在输入框正上方、与输入框同宽（`--layout-max-chat-composer`）。
- 每条右侧：常驻的「调整方向」文字按钮 + 常驻的删除图标按钮（`trash-2`，悬停转危险色）；第 2 条起额外有「插到最前」图标，悬停才出现。
- 删除不藏在 hover 后面 —— 排错了要能立刻撤掉。「调整方向」用文字而非铅笔图标，把它和删除的权重区分开。
- 正文最多 2 行截断，引用胶囊最多 3 个（`size="sm"`），其余折为 `+N`。
- 默认展开 3 条，其余折叠为「还有 N 条」。
- 生成结束后自动出队；队列为空时组件整体不渲染（返回 `null`），不留空壳。
- 生成期间的发送按钮应改为「加入队列」语义（次级底色 + `list-plus` 图标），让用户知道这次点击不会打断当前回答。

## 反例

- 不要用弹层或抽屉承载队列：排队是输入的一部分，不是另一个页面。
- 不要在队列里渲染完整消息气泡 —— 队列是清单，不是对话。
