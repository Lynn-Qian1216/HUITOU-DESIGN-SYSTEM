流程进度与评分环 —— 表格里表示「这条记录走到哪一步了」「这个账户健康不健康」。

```jsx
<ProgressTrack steps={['申请合作', '商品授权', '建广告', '投放中']} at={1} state="pending" label="商品授权" />
<ScoreRing score={85} label="健康度" hint="良好" />
```

`ProgressTrack` 的三态：`done` 已通过（绿）、`pending` 正在处理（红）、`idle` 未启动（全空心 + 中性徽标）。节点悬停显示名称，所以窄列里也不必写全部文字。同一段流程在不同界面必须传同一个 `steps`，否则用户会以为是两套流程。

`ScoreRing` 按档位着色（≥90 绿 / ≥75 琥珀 / 其余中性），不做连续色阶 —— 用户读的是档位。评分口径要在旁边用 `Popover` 说明，别让数字裸奔。
