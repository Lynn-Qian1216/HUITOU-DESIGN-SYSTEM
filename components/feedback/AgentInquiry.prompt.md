智能体缺少条件、需要你补参数时用它 —— 尤其是子 Agent 超时或取数失败之后。

```jsx
<AgentInquiry
  question="分析投放列表表现时，你希望我看哪个时间窗口和数据范围？"
  questions={[
    { key: 'window', label: '时间窗口', options: ['昨天', '近 3 天', '近 7 天', '近 30 天'] },
    { key: 'scope', label: '数据范围', options: ['全部在投计划', '消耗 Top 20 计划', '指定单个计划'] },
  ]}
  defaults={[{ key: 'window', label: '近 7 天' }, { key: 'scope', label: '全部在投计划' }]}
  notePlaceholder="例如：只看藤椒味相关的计划"
  dispatchedAt="13:26" eta="预计 2 min" />
```

规则：

- **不要用灰字提示代替它。** 智能体要参数就给可作答的控件，选项即答案。
- 主操作在选满前保持禁用，同时给一条「用默认范围」的出口，别把人堵死。
- 提交后卡片折成回执：答案留在原位可查，并给「改一下范围」允许返工。
- 等待期间界面上**不出现任何数据或结论** —— 空跑的数字比没有数字更糟。
- 放在对话流里，跟着气泡宽度走；不要包 `Card`。
