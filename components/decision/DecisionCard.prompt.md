AI 决策队列里的单条卡片。信息按「决策本身 → 来源 → 现在到了什么数 → 出口」四层排，一屏扫下来先看到要改什么。

```jsx
<DecisionCard decision={d} onOpen={() => setOpen(d)} onAct={(next) => move(d.id, next)} />
<DecisionActions status="失败" onAct={retry} />   {/* 详情页底栏单用 */}
```

状态驱动整张卡，不要在外面另做条件渲染：

- **待执行／已拒绝** 显示目标（`goal`）；**验证中／失败／已执行** 换成 `MetricRounds`。验证一旦开始，「当初想干什么」就不如「现在到了什么数」重要。
- **已拒绝／已失效** 的改动数值压灰并划掉——它们是记录，不是待办。回滚过的不划掉，靠 `resultText` 说明。
- `impact` 的标题随状态在「预计影响／实际影响／原预计影响／验证结果」间切换，颜色只在真正拿到收益时才是绿的。回滚、过期、被拒都属于「这笔收益没发生」，显示成绿色等于谎报战果。

状态区分靠描边轻重，不要加左侧色条——一列卡片挂五条彩带只剩噪音。

`DecisionActions` 的出口是设计的一部分：失败的主操作是「调整后重试」而不是原样重跑（同样的参数还会失败一次），验证中要留一条「立即回滚」（数不对时人得能立刻停手）。
